# Residue - Circular Economy Marketplace Platform

This project is a web-based circular economy marketplace platform focusing on industrial waste management and repurposing.

## Documentation

- [GEMINI.md](GEMINI.md) - Main guide for project technology stack, building, running, styling conventions, and image optimization.
- [Tools Documentation](.dec/tools/README.md) - Detailed guide for the PNG to WebP image conversion utility.

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Compile CSS in watch mode:
   ```bash
   pnpm watch
   ```

3. Optimize images to WebP:
   ```bash
   pnpm convert-png
   ```
